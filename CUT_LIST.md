# Cut list

- Real CRM, call-intelligence, enrichment, knowledge-store, and notification integrations: synthetic adapters are enough for the scored loop.
- Authentication and multi-tenancy: no users or permissions are needed for the demo.
- Multiple seams, holiday calendars, analytics, evaluation harness, PDF export, and production deployment automation: they would delay the event-to-decision vertical slice.
- Model fine-tuning and vector administration UI: feedback adjusts transparent ranking counters instead.

At 10× volume, JSON file writes, startup embedding work, and synchronous LLM calls are the first constraints. A production follow-up would move state to a database, precompute embeddings, add a job queue, and make triggers durable.
